AEmulator Neo

Boot a real Android 1.0–17 system image straight from a firmware file, running inside a normal Android app.

Download Github Page

What it does

It translates the old ARM code with a patched QEMU, emulates the kernel's binder, draws with your phone's GPU and plays sound through Android's audio stack.

Import almost any firmware

Bring your own image. Android-x86, TWRP ZIPs, Samsung Odin, Google factory images, OTA packages and more.

Vendor skins as shipped

HTC Sense, Samsung TouchWiz, MIUI and AOSP work when the firmware is compatible.

Hardware graphics and sound

GPU drawing through a GL bridge, audio, touch and multitouch.

Modern network access

Old systems reach today's HTTPS sites through a modern TLS proxy.

Shared memory-card folder

Move APKs, music and photos between your phone and the emulated system.

VM screen themes

The navigation bar and frame follow a theme: Original, Sunset, Gingerbread 2.x, Honeycomb 3.x, Holo 4.x, Lollipop 5.x or your own.

Formats include .iso .tar.md5 .tgz system.img system.new.dat.br .sbf .pac .nbh RUU.exe, sparse images and EDL images.

Install

  1. Download the APK from the latest release.
  2. Allow installing from this source when Android asks.
  3. Open AEmulator Neo and add a firmware file.
